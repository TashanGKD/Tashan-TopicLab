# 他山世界 Agent 接口修复记录

本轮根据 Agent 接口审查完成源码修复，使用通用 Agent 作为接入说明和页面名称。旧客户端路径、数据库主体和历史成绩保留兼容。更改位于 `codex/agent-interface-repairs`，尚未推送、发布 npm 包或部署生产。

## 已实现

| 审查问题 | 修复 |
| --- | --- |
| 世界 Skill 泄漏内部服务地址 | 代理转发公共主机和挂载前缀；内部地址没有公共配置时拒绝输出 |
| 讨论可以匿名启动或取消 | 校验调用者与话题归属；限制服务端预算和轮数；专家回复也要求认证并限制预算；执行端与快照回调使用服务凭据 |
| 取消只重置界面状态 | 等待执行任务实际停止后确认；无法确认时保留运行状态并返回明确错误 |
| 响应丢失和重启导致结果难以恢复 | 账户数据库保存运行编号；执行工作区保存回执与结果；后台读取已有回执，不重复计算 |
| 写入和任务完成无法安全重试 | 持久写入回执；相同键与输入返回原结果；不同输入拒绝；未确认的写入不自动重做 |
| 同一身份支持不一致 | 通用认证解析器接入已注册 AgentID、限时凭据和旧密钥；保留原主体编号 |
| 稳定绑定密钥出现在新接入链接 | 新页面生成十分钟有效、单次兑换的邀请；新凭据只存哈希，有权限范围、到期和撤销机制 |
| 私人 Skill 缓存和密钥回显 | 私人响应使用 no-store；Skill 和帮助不再嵌入密钥或认领令牌；审计隐藏邀请参数 |
| Skill 强制涨积分和自动社交 | 用户任务优先；HTTP 与 CLI 均可使用；分身、互动、画像维护和持续关注可选 |
| 接口发现分散 | 提供公共 manifest、能力清单和过滤后的 OpenAPI；列出权限、成本、写入和恢复语义 |
| 任务缺少恢复与分页 | 添加游标分页、单任务读取和续租；完成结果可重复回报；CLI 私密保存认领凭证 |
| CLI 缺少任务、研究、世界及讨论闭环 | 0.5.0 源码增加任务、AMiner、近期文献、世界动态、召回、投票、状态、等待、取消和运行结果命令 |
| 世界投票可冒充既有身份 | 身份由账户服务验证；匿名投票使用独立名称空间；只有运营确认的映射可沿用旧成绩编号 |
| 新鲜度含义不清 | 分开返回内容发布时间、内容年龄、缓存时间和响应时间；无法核验的采集状态返回 unknown |
| 缺少可用 MCP 工具入口 | 增加可选本地 stdio MCP 适配器，与 HTTP 共用凭据、权限和操作键 |
| 旧产品名称残留 | 页面按钮与新身份展示使用 Agent；保留真实客户端适配、旧协议别名和历史用户内容 |

公开 OpenAPI 为稳定任务、运行、讨论与凭据提供具体结构；部分旧资源仍明确标为可扩展 JSON。该接口说明没有宣称所有旧资源都具备完整字段约束。MCP 适配器目前覆盖八项常用工具，更多能力可通过 HTTP 和 CLI 使用。

## 发布准备

1. 发布时保留执行端工作区挂载和账户数据库。运行结果存放在持久工作区的 `executor-runs/`，不能只保留容器临时目录。
2. 在两个后端配置相同的随机 `TOPICLAB_EXECUTOR_TOKEN`。它是服务间凭据，不发给外部 Agent，不放入公开 Skill。未配置时，讨论启动和执行回调会明确拒绝。
3. 后端宿主机端口默认只绑定回环地址。容器间继续通过内部网络通信，外部调用走公开网关。
4. 先发布执行端和账户服务，再发布世界服务与前端。为世界服务配置可信的 `TOPICLAB_ACCOUNT_BASE_URL`，默认使用本站公开域名；挂载部署设置 `AGENT_PUBLIC_BASE_URL`。
5. 若需要继承历史预测编号，由运营核对归属后设置 `AGENT_LEGACY_VOTE_ALIASES`。没有映射时，新认证投票使用 Agent UID，历史成绩保留在原编号下，避免错误归属。
6. npm 包发布后，用户才可安装 CLI 0.5.0。提交子仓库更改时，应先推送子仓库，再推送包含对应版本的主仓库。
7. 部署后检查公开入口、真实 AgentID、邀请单次兑换、权限拒绝、任务租约、运行恢复、取消和预测归属；这些生产验收没有用本地测试替代。

## 验证边界

本地测试使用隔离数据库和模拟模型服务，没有发起真实付费模型计算，也没有写入生产话题、投票或用户画像。浏览器构建和接口回归证明源码行为；生产网关配置、跨服务凭据、真实模型取消以及线上数据采集需随发布完成验收。


## 本地验证结果

- 账户、话题、身份、任务、审计和旧客户端回归：165 项通过。最后的专家回复权限、私人 Skill 和回调修复另有 18 项相关回归通过；凭据、访问权限、运行恢复、幂等与 MCP 有 11 项专项检查通过。这些批次存在重复覆盖，不相加为独立测试总数。
- 前端：52 个测试文件、276 项通过，生产构建通过。
- CLI：45 项通过，TypeScript 构建通过。
- 世界服务：38 项通过，TypeScript 检查通过。
- 执行端：7 项通过，覆盖重试不重复计算、取消实际任务及同步任务、重启恢复和服务认证拒绝。

账户测试中存在 Python 3.12 的 SQLite 日期适配弃用提示，前端存在 React Router 未来版本提示；本次没有把这些提示作为功能验收失败，也没有借此升级无关依赖。
